## 📚 シナリオ

あなたは `expressjs/express` の実際のリポジトリを使って作業します。

**タスク**: Express アプリケーションに新しいルート `GET /healthcheck` を追加したい。  
このルートは `{ status: 'ok', uptime: process.uptime() }` を返すだけのシンプルなものです。

**ゴール**: 変更が必要なファイルと、変更箇所の候補を5分以内に特定すること。

```
リポジトリ: https://github.com/expressjs/express
ローカルパス: （クローン済みの express/ ディレクトリ）
```

---

## 🔍 演習問題

### 問1（構造の把握：3分以内）

`expressjs/express` のリポジトリを開き、**以下のファイルだけ**を確認してください（実装コードは読まない）：

- `package.json` の `main` フィールド
- ルートディレクトリの構成（`ls` または GitHub上で確認）

上記だけを見て、以下に答えてください：

1. このプロジェクトのエントリポイントはどのファイルですか？
2. ルーティング関連のコードがありそうなディレクトリはどこですか？

---

### 問2（読む順番の設計）

`GET /healthcheck` を追加するために、**どのファイルを変更する必要があるか**を仮説として書き出してください。

> 実際のファイルを開く前に書くこと。正確さより「仮説を立てる速さ」が大切です。

---

### 問3（検証：ファイル探索）

以下の探索コマンドを実行して、仮説を検証してください。

```bash
# Express リポジトリのルーティング関連ファイルを探す
# （クローンしたディレクトリで実行）

# ディレクトリ構成を確認
ls -la

# ルーターの実装がありそうなファイルを探す
find . -name "*.js" -not -path "*/node_modules/*" | head -20

# "router" という単語が含まれるファイルを探す
grep -rl "router" --include="*.js" . | grep -v node_modules
```

探索結果と問2の仮説を比較して、**修正すべきファイルの候補**を絞り込んでください。

### 問5（実際に変更してみる）

特定したファイルに、以下のコードを追加してみてください。

```javascript
app.get('/healthcheck', (req, res) => {

```
