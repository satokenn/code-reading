### 問2（スタート地点の特定）

`flask run` コマンドはどこで定義されているか、以下の手順だけで特定してください。

```bash
# step 1: package.json 相当のファイルを確認
cat pyproject.toml  # または setup.py, setup.cfg

# step 2: CLI関連のエントリポイントを探す
grep -r "flask" pyproject.toml
grep -r "cli" src/flask/ --include="*.py" -l
```

> 仮説: CLIコマンドを定義するファイルは `__________` だと思う
>
> 根拠: `__________`

### 問3（読む・飛ばすの判断）

CLIのエントリポイントファイルを開いたとき、以下の各要素について「読む / 飛ばす」を判断して記録してください。

| 要素 | 判断（読む/飛ばす） | 理由 |
|---|---|---|
| `import` 文 | | |
| `@click.group()` デコレータの定義 | | |
| `run_command()` 関数のシグネチャ | | |
| `run_command()` 関数の内部実装 | | |
| エラーハンドリングのtry/except | | |
| `click.option()` の各オプション定義 | | |
| `_validate_key()` などのヘルパー関数 | | |

---

### 問4（フロー図の作成）

`flask run` から開発サーバーが起動するまでのフローを、**読んだ箇所だけ**から図にしてください。

> 不明な箇所は `[不明: 推測]` と書いてOKです。完璧な図より「どこがわかってどこが不明か」を明確にすることが目的です。

```
[flask run コマンド実行]
        ↓
[1. ________________]
        ↓
[2. ________________]
        ↓
        ...
        ↓
[N. 開発サーバーがリクエスト待ち状態になる]
```

---

### 問5（読み飛ばし率の計算）

探索ログを振り返り、以下を計算してください。

```
確認したファイル数: ____ 個
そのうち「読んだ」ファイル数: ____ 個
読み飛ばし率: ____ %

確認した関数・セクション数: ____ 個
そのうち「読んだ」もの: ____ 個
読み飛ばし率: ____ %
```

> 読み飛ばし率が 0% に近い場合、「全部読もう」症候群（アンチパターン AP-01）に陥っています。  
> 目標は **50〜80%** を意図的に飛ばせること。
